FileBrowser 5.0 Release Notes
=============================

FileBrowser 5.0 is compatible with Django 5.x as well as Grappelli 4.0.

Updates
-------

* Compatibility with Django 5.x and Grappelli 4.0

Update from FileBrowser 4.0.x
------------------------------

* Update Django to 5.0 and check https://docs.djangoproject.com/en/5.0/releases/5.0/
* Update Grappelli to 4.0.x
* Update FileBrowser to 5.0.x
